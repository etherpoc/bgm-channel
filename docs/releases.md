# リリース対応表

各動画(リリース)が「どのプロンプトから作られ、メディアがどこにあり、どのYouTube動画になったか」を辿るための対応表。
当たった動画から逆引きで効いたプロンプトを特定でき、`knowledge/insights.md` の逆算材料になる。

| release | 使用prompt id | assets場所 | YouTube URL | 公開日 | 備考 |
|---|---|---|---|---|---|
| ep01-rainy-lofi | 2026-06-14-001, 2026-06-14-101 | bgm-assets/ep01-rainy-lofi/ | - | - | サンプル行。実際の制作に置き換え |

## 運用メモ

- `使用prompt id` は `prompts/*.yaml` の id を列挙する(音・画像とも)。
- `assets場所` はリポジトリ外の実体の場所(ローカルパス / `gs://...` / Drive リンク等)。
- 公開したら `YouTube URL` と `公開日` を埋める。
- 1リリース = bgm-assets 配下の1フォルダ、に対応させると管理が楽。
